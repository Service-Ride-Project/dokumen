# Informasi Umum ServiceRide

## 1. Tentang Aplikasi

ServiceRide merupakan aplikasi yang dirancang untuk menghubungkan customer atau pemilik kendaraan dengan penyedia jasa servis kendaraan atau bengkel secara digital.

Aplikasi ini membantu customer dalam melakukan booking servis, memilih bengkel dan jadwal, melakukan troubleshooting awal terhadap keluhan kendaraan, memperoleh estimasi biaya, menggunakan layanan pickup dan delivery kendaraan, memantau proses servis, serta melakukan pembayaran.

ServiceRide juga menyediakan sistem operasional bagi pihak bengkel untuk mengelola booking, layanan servis, jadwal, mekanik, driver, pemeriksaan kendaraan, perubahan biaya, serta status pengerjaan kendaraan.

## 2. Versi Aplikasi

| Komponen | Versi Saat Ini | Keterangan |
|---|---|---|
| ServiceRide | Belum ditetapkan | Versi utama keseluruhan sistem |
| ServiceRide Frontend | Belum ditetapkan | Aplikasi frontend menggunakan React, Vite, TypeScript, Tailwind CSS, dan shadcn/ui |
| ServiceRide Backend | Belum ditetapkan | Backend menggunakan Golang dengan PostgreSQL, pgvector, Redis, dan sqlc |

Versi frontend dan backend merupakan versi turunan dari ServiceRide, tetapi masing masing dapat memiliki siklus pengembangan dan release yang berbeda.

Contoh skema versioning yang nantinya dapat digunakan:

`ServiceRide 1.0.0`

`Frontend 1.0.0`

`Backend 1.0.0`

## 3. Repository GitHub

Source code ServiceRide dipisahkan menjadi repository frontend dan backend di dalam organisasi GitHub Service Ride Project.

| Repository | Tautan |
|---|---|
| Frontend | https://github.com/Service-Ride-Project/serviceride-frontend |
| Backend | https://github.com/Service-Ride-Project/serviceride-backend |

Frontend menggunakan Vite, TypeScript, React, Tailwind CSS, dan shadcn/ui, sedangkan backend dibangun menggunakan Golang dengan PostgreSQL, pgvector, Redis, dan sqlc.
